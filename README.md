# Red Pulse – Blood Management System

## About
Red Pulse is an Android-based Blood Management System developed as part of a Mobile Application Development academic project. The application aims to provide a mobile platform for blood-management-related activities.

## Technologies Used
- Java
- Android Studio
- Gradle
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Messaging
- Google Maps API

## Requirements
- Android Studio
- JDK 17
- Android SDK 35
- Minimum Android Version: Android 7.0 (API 24)

## Installation

1. Clone the repository:

   `git clone https://github.com/princebytex/red-pulse.git`

2. Open the project in Android Studio.
3. Configure Firebase by adding your `google-services.json` file inside the `app` directory.
4. Configure the required Google Maps API key.
5. Sync the Gradle project.
6. Build and run the application.
